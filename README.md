# 캠퍼스 플래너 PRO

PRD와 화면 설계서를 바탕으로 만든 반응형 캠퍼스 일정 관리 웹앱입니다. 로그인 없이 일정 등록, 수정, 완료 처리, 삭제, 검색, 과목·유형 필터와 D-Day 표기를 지원합니다.

## 실행

Node.js 20 이상이 필요하며 별도 패키지 설치는 없습니다.

```powershell
node server.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 여세요. 일정은 브라우저의 localStorage에 저장되며, 같은 브라우저에서 다시 열어도 유지됩니다.

일정 데이터는 저장한 브라우저에만 남으며 다른 기기와 동기화되지 않습니다. 브라우저 사이트 데이터를 지우면 저장된 일정도 삭제됩니다.

## 참고

오늘 수업 패널은 제공된 디자인 문서의 화면 예시를 반영합니다. 달력 아래 수강과목 카드와 로그인은 제외했습니다. LMS 자동 수집은 PRD의 제외 범위에 따라 동작하지 않습니다.
