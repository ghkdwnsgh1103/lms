# 캠퍼스 플래너 PRO

PRD와 화면 설계서를 바탕으로 만든 반응형 캠퍼스 일정 관리 웹앱입니다. 이메일 계정별 일정 등록, 수정, 완료 처리, 삭제, 검색, 과목·유형 필터와 D-Day 표기를 지원합니다.

## 실행

Node.js 20 이상이 필요하며 별도 패키지 설치는 없습니다.

```powershell
node server.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 여세요. 데이터는 이 프로젝트의 `data/campus-planner.json`에 저장되고 Git에는 포함되지 않습니다. 비밀번호는 scrypt 해시로 저장됩니다. 로그아웃 후 다시 로그인해도 계정과 일정 데이터가 유지됩니다.

이 실행 방식은 개인 PC에서 사용하는 로컬 MVP입니다. 계정 데이터 저장과 인증은 이 서버 인스턴스에 한정됩니다. 여러 기기 동기화와 공개 서비스 운영에는 공유 서버 데이터베이스, HTTPS, 배포 환경에 맞는 세션 저장소와 운영 보안 설정이 추가로 필요합니다.

## 참고

수강과목 카드와 오늘 수업 패널은 제공된 디자인 문서의 화면 예시를 반영합니다. 계정별 일정 데이터는 가입 후 직접 입력하며, LMS 자동 수집은 PRD의 제외 범위에 따라 동작하지 않습니다.
